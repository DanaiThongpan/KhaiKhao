# 📝 รายงานสรุปโปรเจกต์ KhaiKhao (ขายข้าว)

รายงานฉบับนี้จัดทำขึ้นเพื่อรวบรวมข้อมูลโครงสร้างระบบ และสรุปการแก้ไขปรับปรุงโค้ดล่าสุด เพื่อให้ทีมผู้พัฒนาสามารถอ่านและทำความเข้าใจโปรเจกต์ได้อย่างรวดเร็ว

---

## 📌 1. ภาพรวมโปรเจกต์ (Project Overview)
โปรเจกต์ **KhaiKhao** เป็นระบบจัดการร้านอาหารและจุดขาย (POS) แบบครบวงจรที่พัฒนาด้วย **Django (Python)** โดยมีฟังก์ชันครอบคลุมตั้งแต่การจัดการหน้าร้าน, คลังสินค้า, ระบบบัญชี, ไปจนถึงการจัดการไรเดอร์และหอพักเป้าหมาย

**Tech Stack หลัก:**
- **Backend:** Django 4.2+ (Python)
- **Database:** SQLite (`db.sqlite3`)
- **Authentication:** Custom User Model 
- **Integrations:** รองรับ Google APIs (ผ่าน `service_account.json`) และระบบอ่านสลิป (OCR) ด้วย `pytesseract`

---

## 🧩 2. โครงสร้างแอปพลิเคชัน (Architecture)
ระบบถูกแบ่งออกเป็นโมดูล (Apps) อย่างชัดเจน ดังนี้:

### 🛒 หน้าร้านและสินค้า
- **Pos:** ระบบบันทึกการขาย, ตรวจสอบสลิปโอนเงิน (มีระบบ OCR), บันทึกออเดอร์
- **Products:** ระบบจัดการรายการสินค้า, หมวดหมู่ และราคา
- **Stocks:** ระบบติดตามปริมาณวัตถุดิบและสินค้าในคลัง (พร้อมประวัติการนำเข้า-ออก)

### 🛵 ระบบจัดส่ง (Delivery)
- **Riders:** ระบบจัดการข้อมูลไรเดอร์, รายชื่อหอพักเป้าหมาย และงานจัดส่ง (Delivery Tasks)

### 💰 การเงินและบัญชี
- **Expenses:** ระบบบันทึกรายจ่ายต่างๆ ของร้าน (มีการเชื่อมต่อ Google Calendar)
- **Taxes:** ระบบคำนวณและบันทึกภาษีประจำปี (เปลี่ยนชื่อมาจาก *Taxs*)

### 👥 ผู้ใช้งานและข้อมูลสถิติ
- **Accounts:** จัดการบัญชีผู้ใช้และพนักงาน (Custom User)
- **Reports & History:** ดูสถิติยอดขาย, ประวัติการทำรายการ, และความหนาแน่นของการจัดส่ง (Heatmap)
- **ShopHistory:** บันทึกกะการทำงาน (เวลาเปิด-ปิดร้าน)
- **BackOffice:** แผงควบคุมระบบหลังบ้านสำหรับผู้ดูแล

## 🛠️ 3. สรุปการปรับปรุงโค้ดล่าสุด (Recent Refactoring)
ได้ทำการคลีนโค้ดและแก้ไขข้อผิดพลาดเพื่อให้ระบบเสถียรขึ้น ดังนี้:

1. **แก้ไข Bug การรันระบบ (Missing Dependencies):**
   - เพิ่ม `pytesseract==0.3.10` ลงใน `requirements.txt` เพื่อแก้ปัญหา `ModuleNotFoundError` ในหน้าสแกนสลิป
2. **ปรับปรุงการอ่านชื่อหอพัก (DRY Principle):**
   - ใน `Pos/views.py` ได้รวบรวมโค้ดเช็คชื่อหอพักที่ซ้ำซ้อนกัน สร้างเป็น Helper Function ชื่อ `_get_dorm_name()`
   - อัปเดตข้อความแสดงผลค่าเริ่มต้นเป็น `"อยู่ระหว่างรวบรวมข้อมูลหอพัก"` ให้ตรงกับหน้า UI
3. **แก้ไข Typo ชื่อแอปพลิเคชัน:**
   - เปลี่ยนชื่อแอปจาก `Taxs` เป็น **`Taxes`** ในทุกจุดของโค้ด (รวมถึงการผูกชื่อตาราง Database เดิม `taxs_taxrecord` เพื่อไม่ให้กระทบข้อมูลเก่า)
4. **ยกระดับการจัดการ Error (Logging):**
   - ใน `Expenses/views.py` ได้เปลี่ยนจากการใช้ `print()` เมื่อเกิด Error ใน Google Calendar มาใช้ไลบรารี `logging` ของ Python แทน
